What it is

A low-poly 3D city-builder that gives mobile players the systems depth they've never had on a phone. Think Cities: Skylines' simulation meeting Townscaper's painterly polish meeting SimCity's political layer — all running natively in a browser at 60fps on a Pixel 7.

Real city simulation

Cars route via A* on a road graph. Pedestrians use a separate path graph. Traffic congestion propagates upstream and drags down zone demand. Buses follow auto-cycled depot routes. Crime, tourism, and pollution all model per-tile.

10 factions, named leaders, real politics

Every faction has a happiness function tied to game state. Yearly elections re-form a 4-seat council that gates costs, vetoes zoning changes, and shifts population. The mayor (player) navigates a real political layer, not a sliders panel.

4 civic monuments built block-by-block

Mayor's Mansion (4×2), City Hall (5×3), Provincial Capital (6×4), National Capital (7×4). Each placed per-tile over weeks of in-game time with visible construction sites + crane geometry. All rotatable.

4 density tiers + skyscrapers

R / C / I / Mixed-Use × Low / Medium / High / Max. Plus 2×2 skyscrapers with a 4-stage construction over 12 sim months — each stage is its own visible build site (foundation, steel skeleton, facade going up, finished tower).

Real economy on a sim-month tick

Treasury, R/C/I tax sliders, monthly settlement, bond issuance (3 tiers), wealth surtax brackets, district-level surtax, lumber + produce export markets with oscillating global prices.

Day/night cycle with real lighting

Sun arcs across the sky. Skyscrapers light up at night. Street lamps cast pools. Parks glow. Mansion + monuments emit accent lighting for late-night aerial photo mode.

Random events drive replayability

Recessions, fires, lawsuits, referendums. Each one shifts modifiers (faction moods, market prices, demand) and surfaces a severity-tinted decision modal. Choice events block until the player picks.

240-month stats panel

Native canvas line graphs for population, treasury, mood, RCI demand, export revenue — captured at every month rollover. No chart library; lightweight + fast.

Civic actions + political capital

Endorse a faction. Form a coalition. Stage a photo-op when you build something popular. Trigger a Mayoral Override to bypass the council for one term. All powered by accumulating Political Capital — a single resource, not a currency to be bought.

Why it works on mobile (where almost no city-builder does)

Most mobile city-builders are downsized desktop ports — they assume a mouse, get cramped on small screens, and use timers / energy systems to fake depth. MQ City Builder was built mobile-first from day one. The proof: it's already running great in a browser tab on every phone made in the last 5 years.

✓
Custom pointer-events handler built for touch. Pinch zooms from the gesture midpoint. Two-finger pan. Long-press for context. Same code path covers mouse + pen so it scales to tablets and the web without rewrites.
✓
One-handed playable. Toolbar pinned to the bottom edge, reachable with a thumb. All buttons ≥44pt. The full game can be played in portrait orientation without scrolling the HUD.
✓
60fps on Pixel 7 / iPhone 13. Sim decoupled from render: simulation runs at 10Hz, rendering at 60Hz. Spatial hashing for proximity queries. InstancedMesh for repeating geometry. Performance was the second-most-tracked goal after fun.
✓
Tiered map sizes. Small (64×64) runs on a 2021 mid-range Android. Medium (128×128) is the default. Large (256×256) for flagship phones + tablets.
✓
PWA installable. Already has manifest + service worker + custom icon. iOS / Android home-screen install works today. Opens like a native app, runs offline once loaded.
✓
Cloud saves with cross-device sync. Supabase auth + per-account save store. Same city on phone + tablet + laptop. 3 save slots with rename + city naming.
✓
Tutorial + playtest infrastructure. Live tutorial coach watches the player and advances when they hit milestones. Skippable. Re-launchable from settings.
✓
Easy native-app wrap. Capacitor wraps the existing web build into iOS / Android shells. ~1 week of work, no engine rewrite needed.

What's already built (the de-risking section)

The hardest engineering — the simulation, the rendering, the save system, the auth, the deployment pipeline, the cross-device sync — is shipped and stable. A publisher signing today is signing a finished product, not a promise.

Engine + simulation

TypeScript strict mode. Three.js renderer with a custom orthographic 3/4 camera. Decoupled sim tick (10Hz) and render tick (60Hz). Full ECS-style separation of world, simulation, and rendering systems. ~50 source files, ~30K lines, no `any` types.

Save system

Schema v27 with full backwards compatibility back to v2. IndexedDB local + Supabase cloud sync. Portable city codes (gzipped base64) so players can share city saves through any text channel. ~87KB per typical 128×128 save, compressed.

Auth + cloud

Supabase-backed accounts (email + password + magic link + OAuth scaffolding). Row-level security policies enforce per-user isolation. Auto-deploy via GitHub Actions on every push to main.

Deployment + ops

Custom domain (mqcity.app) with auto-provisioned Let's Encrypt SSL. GitHub Pages hosting at zero cost. Bundle ~1MB raw / 257KB gzipped — fits in mobile cellular range. PWA service worker for offline.
